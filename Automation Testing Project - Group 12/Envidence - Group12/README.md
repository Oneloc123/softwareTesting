# Envidence - Group12

Thư mục này được reporter `scripts/evidence-reporter.js` điền tự động trong mỗi lần chạy Playwright. Mỗi `RUN_ID` có một thư mục riêng gồm screenshot, log JSON và video của test lỗi (nếu Playwright tạo attachment video).

ZIP nguồn chưa chứa screenshot/log thực thi của một lần chạy thực tế. Vì vậy thư mục hiện chỉ có README, không chứa ảnh hoặc log minh chứng giả. Chạy `npm test` từ thư mục gốc để tạo minh chứng.
