# Test Report - Group 12

Báo cáo chạy thật được Playwright tự động sinh sau lệnh `npm test`:

- `html-report/index.html` — báo cáo HTML tương tác.
- `results.json` — kết quả dạng JSON.
- `junit.xml` — kết quả dạng JUnit XML.

Trạng thái hiện tại: **Chưa có kết quả thực thi trong ZIP nguồn**. Cần cài dependencies, cấu hình tài khoản demo trong `.env` và chạy toàn bộ Test Suite để tạo các file báo cáo. Không có kết quả Pass/Fail nào được giả lập trong thư mục này.
