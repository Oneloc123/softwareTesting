# Thành phần test của Nam

Các test JavaScript của Nam nằm trong `tests/`; Page Objects, fixtures và tiện ích nằm trong `src/`; dữ liệu kiểm thử nằm trong `test-data/`.

Thành phần này sử dụng cấu hình Playwright dùng chung ở thư mục gốc. Xem `../README.md` để cài đặt, cấu hình tài khoản và chạy `npm run test:nam` hoặc `npm test`.
